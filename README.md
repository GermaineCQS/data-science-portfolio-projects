# Data Science Portfolio Projects

Este repositorio contiene una seleccion de proyectos desarrollados durante mi
formacion como Ingeniero en Datos y Cientifico de Datos, enfocados en analisis
de datos y machine learning.

El objetivo de este repositorio es servir como soporte tecnico de mi portafolio
profesional y mostrar de manera practica mis habilidades y forma de trabajo.

## Proyectos incluidos

- [Prediccion de riesgo de diabetes](diabetes-risk-prediction)
  - Clasificacion y evaluacion de modelos para estimar riesgo de diabetes.
- [Optimizacion de recuperacion de oro](gold-recovery)
  - Modelado y analisis de procesos industriales para mejorar la recuperacion.
- [Analisis de datos de Spotify](spotify-data-analysis)
  - Exploracion y visualizacion de datos musicales y patrones de consumo.

Cada proyecto cuenta con su propia carpeta, documentacion y codigo asociado.

## Tecnologias principales

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook
- Matplotlib / Seaborn

## Como navegar el repositorio

Cada carpeta contiene notebooks y archivos auxiliares del proyecto. Revisa los
README internos si estan disponibles para ver objetivos, dataset y resultados.
