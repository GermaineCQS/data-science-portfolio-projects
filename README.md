# 📊 Data Science Portfolio Projects

Este repositorio contiene una selección de proyectos desarrollados durante mi
formación como **Ingeniero en Datos / Científico de Datos**, enfocados en el
análisis de datos y machine learning.

El objetivo de este repositorio es servir como soporte técnico de mi portafolio
profesional y mostrar de manera práctica mis habilidades y forma de trabajo.

## 🚀 Proyectos incluidos

- **Clasificación de reseñas de películas (NLP)**
- **Predicción de precios de autos usados**
- **Análisis estadístico de planes móviles**
- **Optimización de recuperación de oro**
- **Análisis de datos de Spotify**

Cada proyecto cuenta con su propia carpeta, documentación y código asociado.

## 🛠 Tecnologías principales
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook
- Matplotlib / Seaborn
