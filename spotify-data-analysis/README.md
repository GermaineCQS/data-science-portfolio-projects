# 🎧 Análisis de datos de Spotify

Proyecto de analítica de datos basado en tres bases de datos relacionadas con
Spotify. El objetivo es explorar patrones de popularidad, género musical y
consumo para generar insights accionables.

## 🎯 Objetivo
Integrar y analizar tres datasets de Spotify para responder preguntas clave sobre
popularidad, géneros musicales y comportamiento de consumo.

## 🧠 Desarrollo del proyecto
- Integración de tres fuentes de datos (tracks, detalles y artistas)
- Limpieza y estandarización de variables clave
- Selección de artista principal por track (max followers)
- Análisis de artistas, géneros y singles más escuchados
- Ranking de álbumes sin duplicados

## 🛠 Tecnologías utilizadas
- Python
- Pandas
- NumPy
- Matplotlib / Seaborn
- Jupyter Notebook

## 📊 Resultados destacados
- Top 10 artistas con más followers
- Géneros más populares por volumen y por popularidad promedio
- Singles más escuchados del top 10k
- Álbumes más escuchados (sin duplicados)

## 📂 Contenido de la carpeta
- `data/`: datasets originales de Spotify
- `notebook.ipynb`: integración y análisis de preguntas clave
- `src/`: scripts de limpieza y análisis (futuro)
- `results/`: gráficos y salidas finales (futuro)
