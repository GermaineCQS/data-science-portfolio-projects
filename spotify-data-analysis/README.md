# Spotify Data Analysis

## Introducción

La industria del streaming musical genera grandes volúmenes de datos sobre preferencias de los usuarios, tendencias de consumo y desempeño de los artistas.  
En este proyecto se realizó un análisis exploratorio de datos de Spotify con el objetivo de identificar patrones en canciones, artistas y características musicales que influyen en la popularidad dentro de la plataforma.

Este proyecto forma parte de mi portafolio profesional y demuestra mi capacidad para transformar datos en información útil para la toma de decisiones.

---

## Contexto del problema

Las plataformas digitales necesitan comprender qué factores hacen que una canción tenga mayor aceptación entre los usuarios.

El problema principal del proyecto fue:

**¿Qué características musicales están más relacionadas con la popularidad de una canción en Spotify?**

Responder esta pregunta puede ayudar a:

- entender preferencias de los usuarios
- identificar tendencias musicales
- apoyar decisiones de marketing
- mejorar recomendaciones personalizadas
- analizar comportamiento del mercado musical

---

## Objetivo del proyecto

El objetivo principal fue analizar el dataset para:

- explorar variables musicales
- detectar patrones de popularidad
- comparar artistas y géneros
- identificar relaciones entre variables
- extraer conclusiones útiles del comportamiento musical

## Resultados

Los resultados mostraron que:

- canciones con mayor **energy** tienden a obtener mejor recepción
- niveles moderados de **danceability** se relacionan con mayor popularidad
- algunos géneros muestran patrones consistentes en características acústicas
- artistas con estilos definidos mantienen métricas similares entre canciones

La hipótesis inicial fue:

**Las características musicales influyen en la popularidad de una canción.**

Esta hipótesis se cumplió parcialmente, ya que algunas variables mostraron relación significativa mientras otras tuvieron un impacto menor al esperado.

---

## Conclusiones

A partir del análisis se concluyó que:

- la popularidad musical no depende de una sola variable
- existen combinaciones de características que influyen más
- algunos géneros responden de manera distinta
- el contexto del artista también puede afectar el rendimiento

Esto demuestra que el análisis de datos puede aportar valor para entender el comportamiento de consumo musical.
