# 🩺 Prediccion de riesgo de diabetes (Mexico)

Proyecto de machine learning enfocado en salud publica para clasificar el
riesgo de diabetes en tres niveles (bajo, moderado, alto) usando variables
clinicas, demograficas y bioquimicas.

## 🎯 Objetivo
Predecir el riesgo de diabetes con un enfoque preventivo y explicable, evitando
data leakage y usando metricas adecuadas para clasificacion multiclase.

## 🧠 Desarrollo del proyecto
- Analisis exploratorio y calidad de datos
- Limpieza, imputacion y tratamiento de atipicos
- Preparacion de variables numericas y categoricas
- Modelos baseline y ensemble
- Evaluacion con metricas multiclase y matriz de confusion
- Interpretabilidad con importancia de variables

## 🛠 Tecnologias utilizadas
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib / Seaborn
- Jupyter Notebook

## 📊 Resultados esperados
Un modelo interpretable que identifique las variables clinicas con mayor peso
en el riesgo, con resultados claros para apoyo preventivo.

## 📂 Contenido de la carpeta
- `data/`: dataset clinico (Diabetes_Mexico.csv)
- `notebook.ipynb`: analisis y modelado completo
- `src/`: scripts auxiliares (futuro)
- `results/`: metricas y salidas (futuro)
