# Diabetes Risk Prediction

## Introducción

La diabetes es una de las enfermedades crónicas más comunes a nivel mundial y su detección temprana puede ayudar a reducir complicaciones médicas a largo plazo.  
Este proyecto tiene como objetivo desarrollar un modelo de machine learning capaz de predecir el riesgo de diabetes en pacientes a partir de variables clínicas y demográficas.

Este proyecto forma parte de mi portafolio profesional como estudiante de Ingeniería en Datos con enfoque en Ciencia de Datos, demostrando mi capacidad para trabajar con datos reales del sector salud.

---

## Contexto del problema

Muchas instituciones médicas generan grandes cantidades de datos clínicos, pero en ocasiones estos datos no son aprovechados para apoyar decisiones preventivas.

El problema principal es:

**¿Es posible identificar pacientes con mayor probabilidad de desarrollar diabetes utilizando modelos predictivos?**

Resolver esta pregunta puede ayudar a:

- detectar pacientes en riesgo
- apoyar decisiones médicas tempranas
- optimizar recursos en instituciones de salud
- mejorar la prevención de enfermedades

---

## Objetivo del proyecto

El objetivo principal fue construir un modelo predictivo que permitiera:

- analizar variables médicas relevantes
- identificar patrones asociados con diabetes
- evaluar distintos modelos de clasificación
