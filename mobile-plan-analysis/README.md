# 📱 Análisis estadístico de planes móviles

## 📌 Contexto
Las empresas de telecomunicaciones ofrecen distintos planes móviles con el objetivo
de maximizar ingresos y satisfacer las necesidades de sus clientes. Evaluar el
desempeño de estos planes mediante datos reales es clave para la toma de decisiones.

## 🎯 Objetivo
Analizar y comparar el comportamiento de los usuarios de distintos planes móviles
para determinar cuál genera mayores ingresos, utilizando análisis exploratorio
y pruebas estadísticas.

## 🧠 Desarrollo del proyecto
- Limpieza y preparación de datos de llamadas, mensajes e internet
- Análisis exploratorio del uso por usuario
- Cálculo de ingresos mensuales por cliente
- Visualización de patrones de consumo
- Formulación y validación de hipótesis estadísticas
- Interpretación de resultados orientados al negocio

## 🛠 Tecnologías utilizadas
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Jupyter Notebook

## 📊 Resultados
El análisis permitió identificar diferencias claras en el comportamiento de los
usuarios y en los ingresos generados por cada plan, respaldadas por pruebas
estadísticas y visualizaciones claras.

## 📂 Contenido de la carpeta
- `notebook.ipynb`: análisis completo y pruebas de hipótesis
- `src/`: scripts auxiliares de análisis (cuando aplique)
- `results/`: gráficos y conclusiones finales
